Run from the Elyra repository root:
  node scripts/fetch-human-base.mjs

This downloads the CC0 rigged human development base to:
  apps/admin/public/models/human-base-rigged.glb

The asset is a REAL skinned humanoid base mesh, not the final Elyra face/body asset.
Final face sculpting requires a production mesh authored with identity morph targets.
