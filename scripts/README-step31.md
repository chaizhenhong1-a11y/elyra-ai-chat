# Step 31 — Neutral stylized topology bootstrap

This step does **not** generate another procedural body and does **not** overwrite `ELYRA_CHIBI_V1`.
It downloads Blender Studio's CC0 Human Base Meshes bundle, selects a stylized body candidate, inspects it headlessly in Blender, and exports a neutral GLB preview plus a topology report.

Purpose: establish a real editable neutral humanoid topology before wiring OpenAI identity parameters into Blender sculpt/morph operations.
